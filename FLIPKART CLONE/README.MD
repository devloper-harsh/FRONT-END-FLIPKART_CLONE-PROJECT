A fully responsive Flipkart clone built with pure HTML5, CSS3, and Vanilla JavaScript.

✨ Features
🔐 Auto-Show Login Modal - Login form appears on page load (like real Flipkart)

🎠 Auto-Sliding Banners - 3 banners with smooth transitions and navigation buttons

📦 52+ Products - Real product data with images, prices, ratings, and discounts

🔍 Search Functionality - Search products by name with results count

📂 Category Navigation - Browse products by categories (Mobiles, Electronics, Fashion, etc.)

📱 Fully Responsive - Optimized for Desktop, Tablet, and Mobile devices

🛒 Interactive UI - Product click adds to cart (demo), view all products, footer links

🎨 Modern Design - Flipkart-inspired UI with clean typography and colors

🛠️ Tech Stack
HTML5 - Semantic markup

CSS3 - Flexbox, Grid, Variables, Animations, Media Queries

JavaScript (Vanilla) - DOM manipulation, Events, Timer functions

Font Awesome 6 - Icons

Google Fonts (Inter) - Typography
